# Security policy

## Report a vulnerability

Please do not disclose vulnerability details in public issues, pull requests, or discussions.

GitHub private vulnerability reporting is enabled for this repository. Open the [Security Advisories page](https://github.com/appunni-m/python-standard/security/advisories) and choose **Report a vulnerability**. If the button is unavailable, contact the maintainer through the [GitHub profile](https://github.com/appunni-m) to arrange a private channel; do not post vulnerability details publicly. GitHub's [private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately) describes the process.

Include the affected version, Python version, impact, and a minimal reproduction. Remove credentials, personal data, and unrelated sensitive information from the report.

## Supported versions

Standard is an alpha project. Security fixes target the latest coordinated
release; older versions may not receive backports. The project declares Python
`>=3.11`, and CI is configured for CPython 3.11 through 3.14.

## Response expectations

Maintainers aim to acknowledge a private report within five business days and provide an initial triage update within ten business days. These are response targets, not guarantees. For a confirmed issue, maintainers will coordinate impact assessment, a fix, and disclosure timing through the private report.
