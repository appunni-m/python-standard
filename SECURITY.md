# Security policy

Standard is published on PyPI. This repository does not currently have a configured private vulnerability reporting channel.

Please do not include credentials, private configuration, or exploitable details in a public issue. Until a private reporting route is configured, contact the repository maintainer through a trusted private channel and ask for a secure way to share the report. Do not send secrets in a public issue.

The supported release versions and response expectations are not yet documented. Maintainers should enable GitHub private vulnerability reporting and publish the secure reporting route, supported versions, and response expectations here.
