# Security policy

Standard has no released runtime package yet. This repository does not currently have a configured private vulnerability reporting channel.

Please do not include credentials, private configuration, or exploitable details in a public issue. Until a private reporting route is configured, contact the repository maintainer through a trusted private channel and ask for a secure way to share the report. Do not send secrets in a public issue.

Before the first runtime release, maintainers should enable GitHub private vulnerability reporting and publish supported-version and response expectations here.
