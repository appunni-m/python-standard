# Support

Standard is an alpha library. Its six distributions share a coordinated
release version; check PyPI for the version you installed. The project
configures CI for CPython 3.11 through 3.14. Start with the
[documentation site](https://appunni-m.github.io/python-standard/) and check
that the installed distribution and extra match the module you are using.

## Ask a question or report a problem

Use [GitHub Issues](https://github.com/appunni-m/python-standard/issues) for
usage questions, reproducible bugs, and feature requests. Before opening an
issue, search existing reports and include:

- the installed Standard version and any integration extra;
- Python version and operating system;
- a short description of the expected and actual behavior;
- the smallest reproducible example and relevant error output.

Remove API tokens, credentials, personal data, and private configuration from
examples and logs. Maintainers do not promise a response time.

## Report a security issue

Do not post vulnerability details in a public issue. Follow the private
reporting process in [SECURITY.md](SECURITY.md).
