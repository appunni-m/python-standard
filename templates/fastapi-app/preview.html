  level: ${LOG_LEVEL:-null}
  format: ${LOG_FORMAT:-auto}

  color: ${LOG_COLOR:-auto}

  enabled: ${HEARTBEAT_ENABLED:-false}

Feature-first file map

follow each module
standard-fastapi-app/
├── config/settings.yaml        # all env placeholders
└── src/example_app/
    ├── main.py                 # compose once
    ├── lifecycle.py            # background start / stop
    ├── core/                   # shared infrastructure
    │   ├── settings.py         # YAML aggregate
    │   └── services.py         # service contracts
    └── modules/
        ├── application/
        │   └── config.py       # app settings
        ├── health/
        │   ├── api/routes.py   # thin controller
        │   ├── models.py       # domain data
        │   ├── schemas.py      # HTTP response
        │   └── service.py      # feature behavior
        └── heartbeat/
            ├── config.py       # feature settings
            └── service.py      # background work

Lifecycle

Keep data with the feature that owns it

The health model is an in-memory domain value, not an ORM model. When a database is chosen, keep that module's persistence models and repository beside its services. Logging comes from std.logging; shared lifecycle primitives come from std.service.
